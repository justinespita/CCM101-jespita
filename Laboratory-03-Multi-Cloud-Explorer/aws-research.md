# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many services that organizations can use to build, deploy, store, and manage applications without having to maintain all of the physical infrastructure themselves. AWS provides services for computing, storage, databases, networking, security, analytics, and many other cloud requirements.

## Global Infrastructure

AWS has a large global infrastructure organized into **Regions** and **Availability Zones**. A Region represents a geographic location where AWS operates cloud infrastructure, while Availability Zones are separate infrastructure locations within a Region. AWS designs its Availability Zones to help organizations build applications with better availability and resilience. AWS currently lists **39 launched geographic Regions and 123 Availability Zones**, with additional infrastructure announced for the future.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services and resources. From the console, users can find AWS services, configure resources, monitor their cloud environment, and manage different aspects of their AWS account. The console provides a central place for accessing individual AWS service consoles.

## Four Core Services

| Service        | Category       | Description                                                                                                                                |
| -------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **Amazon EC2** | Compute        | Provides virtual servers that can be used to run applications and workloads in the cloud.                                                  |
| **Amazon S3**  | Object Storage | Stores and retrieves files and other types of objects using scalable cloud storage.                                                        |
| **Amazon RDS** | Database       | Provides managed relational databases so organizations can run databases without managing all of the underlying infrastructure themselves. |
| **Amazon VPC** | Networking     | Allows users to create and manage a logically isolated virtual network for their AWS resources.                                            |

## Three Advantages

### 1. Wide Range of Services

AWS provides a broad selection of cloud services covering computing, storage, databases, networking, security, analytics, and other technologies. This allows organizations to build different types of applications using services from the same cloud provider.

### 2. Global Infrastructure

AWS operates infrastructure in many geographic regions around the world. This allows organizations to choose locations that can help reduce network latency and meet operational or regulatory requirements.

### 3. Scalability and Flexibility

AWS allows organizations to adjust their cloud resources according to their workload. Businesses can start with the resources they need and increase or decrease their infrastructure as their applications and users change.

## Typical Enterprise Use Cases

AWS can be used by enterprises for many different purposes. Common examples include hosting websites and mobile applications, storing and backing up business data, running databases, supporting e-commerce platforms, processing large amounts of data, and creating disaster recovery environments. Organizations can combine different AWS services to create complete cloud-based systems.
