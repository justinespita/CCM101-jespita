# Laboratory 03 – Multi-Cloud Explorer

## Overview

This laboratory is about exploring and comparing three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). I researched their services, advantages, infrastructure, and common uses. I also compared their equivalent services and recommended cloud platforms based on different business requirements.

## Checkpoint 1 – Expand Your Cloud Portfolio

I created a new folder named `Laboratory-03-Multi-Cloud-Explorer` inside my Cloud Computing portfolio. The folder contains the documents and activities completed for this laboratory.

## Checkpoint 2 – Explore the Three Cloud Platforms

I researched AWS, Microsoft Azure, and Google Cloud using their official documentation and websites. I created separate research files for each platform:

- `aws-research.md`
- `azure-research.md`
- `gcp-research.md`

Each file contains an overview, global infrastructure, cloud management console, four core services, three advantages, and typical enterprise use cases.

## Checkpoint 3 – Compare the Major Cloud Platforms

I compared AWS, Microsoft Azure, and Google Cloud based on their launch year, compute, storage, networking, identity services, strengths, and ideal organizations. I also answered questions about the strengths of each cloud provider and which platform I would personally choose.

## Checkpoint 4 – Cloud Platform Recommendation Challenge

I analyzed four different business scenarios and recommended a suitable cloud provider for each one.

- **Client A – Startup Company:** AWS
- **Client B – University:** Microsoft Azure
- **Client C – AI Research Company:** Google Cloud
- **Client D – Global E-Commerce Company:** AWS

The recommendations were based on the needs and existing technologies of each client.

## Checkpoint 5 – Match the Cloud Services

I compared equivalent services between AWS, Azure, and GCP. The comparison included virtual machines, object storage, identity management, SQL databases, and Kubernetes.

## Checkpoint 6 – Multi-Cloud Decision Matrix

I created a decision matrix for different business requirements, including startup companies, enterprise organizations, Microsoft environments, AI and machine learning, Kubernetes deployment, and global web applications.
