# Mission Reflection

This laboratory helped me understand the differences between AWS, Microsoft Azure, and Google Cloud. The cloud platform that impressed me the most was Google Cloud because of its strong support for Artificial Intelligence, Machine Learning, and Kubernetes. I found it interesting that Google Cloud provides services like Vertex AI, Compute Engine, and Google Kubernetes Engine that can be used for different types of projects.

AWS, Azure, and Google Cloud have many similarities because they all provide common cloud services such as virtual machines, storage, databases, networking, and identity management. Even though they offer similar services, their names, features, pricing, and strengths can be different. This showed me that comparing the services is important before deciding which provider to use.

Business requirements have a big effect on cloud platform selection. For example, Azure can be a good choice for a university that already uses Microsoft products, while Google Cloud can be suitable for an AI research company. AWS can also be a good option for startups and global businesses because of its wide range of services and scalability.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about picking the most popular platform. I need to look at the client's budget, existing technologies, performance requirements, scalability, and the type of application they want to run. I also learned how to compare equivalent services between different cloud providers.

My GitHub Cloud Computing Portfolio has also improved because the laboratory added more organized technical documentation and research. I now have more experience using Markdown, organizing files, documenting Linux commands, and keeping my work in a structured GitHub repository. Overall, this activity helped me understand how cloud technologies can be matched with real business needs.
