# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services that organizations can use to build, deploy, manage, and scale applications and IT infrastructure. Azure offers services for computing, storage, databases, networking, security, artificial intelligence, analytics, and many other cloud technologies.

## Global Infrastructure

Azure has a large global infrastructure consisting of regions, datacenters, and networking infrastructure. Microsoft currently lists more than **80 Azure regions and more than 500 datacenters** around the world. Azure regions are geographic locations containing physical facilities with datacenters and networking infrastructure. This global infrastructure helps organizations meet requirements for performance, availability, data residency, and disaster recovery.

## Cloud Management Console

The **Azure Portal** is a web-based unified console used to create, manage, and monitor Azure resources. Users can manage virtual machines, databases, applications, storage, networks, and other Azure services through the portal. It also provides tools for monitoring resources, managing access, and viewing cloud costs.

## Four Core Services

| Service                    | Category       | Description                                                                                         |
| -------------------------- | -------------- | --------------------------------------------------------------------------------------------------- |
| **Azure Virtual Machines** | Compute        | Provides virtual machines that can run applications and operating systems in the cloud.             |
| **Azure Blob Storage**     | Object Storage | Provides scalable object storage for files, documents, media, backups, and other unstructured data. |
| **Azure SQL Database**     | Database       | A managed relational database service based on Microsoft SQL technologies.                          |
| **Azure Virtual Network**  | Networking     | Allows organizations to create private networks and connect Azure resources securely.               |

## Three Advantages

### 1. Strong Microsoft Integration

Azure works closely with Microsoft technologies such as Windows Server, Microsoft 365, Active Directory, and other Microsoft products. This makes Azure a suitable option for organizations that already depend heavily on the Microsoft ecosystem.

### 2. Global Infrastructure

Azure has a large worldwide infrastructure with many regions and datacenters. Organizations can select appropriate regions based on factors such as user location, latency, availability, and data residency requirements.

### 3. Hybrid Cloud Capabilities

Azure provides tools and services that allow organizations to connect and manage on-premises infrastructure together with cloud resources. This can help businesses gradually migrate existing systems to the cloud instead of moving everything at once.

## Typical Enterprise Use Cases

Azure is commonly used by enterprises for hosting business applications, running Windows Server workloads, managing databases, storing business data, supporting hybrid cloud environments, and developing artificial intelligence applications. Organizations can also use Azure to connect existing on-premises infrastructure with cloud services.
